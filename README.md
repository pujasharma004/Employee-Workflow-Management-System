# Employee-Workflow-Management-System
An employee workflow management system that streamlines request handling, reduces manual routing, and improves workflow visibility and response tracking.
That helps organizations manage, route, prioritize, and track employee requests efficiently.

## Features

- Employee request creation and tracking
- Automatic department-based request routing
- Priority management
- SLA deadline calculation and tracking
- Role-based workflow for Employees, Agents, and Admins
- Request status management
- Analytics dashboard
- RESTful APIs
- JWT-based authentication
- Email notifications for request updates

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- HTML5
- CSS3
- JavaScript
- JWT
- SMTP
